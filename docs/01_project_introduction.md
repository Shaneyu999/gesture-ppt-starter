# 项目介绍与研究方法

## 1. 项目名称

**基于轻量视觉模型的实时手势人机交互系统**

Demo 场景：使用普通摄像头识别四种手势，并控制 PowerPoint 或视频播放器。

## 2. 研究背景

演示文稿和视频播放通常需要鼠标、键盘或遥控器操作。摄像头手势交互可以减少设备依赖，使操作更自然，也可以用于无接触演示、公共展示和辅助交互。

与年龄组识别相比，手势识别具有更直观的视觉线索：

- 手指数量；
- 手掌轮廓；
- 拇指方向；
- 手与身体的位置关系；
- 连续动作变化。

因此它更适合作为图像分类和实时人机交互的入门项目。

## 3. 研究任务

输入是摄像头视频帧，输出是以下四种手势之一：

| 标签 | 手势 | 默认动作 |
| --- | --- | --- |
| palm | 张开手掌 | 播放/暂停 |
| peace | 剪刀手 | 下一张/快进 |
| thumbs_up | 点赞 | 上一张/快退 |
| fist | 握拳 | 静音 |

系统进一步将识别结果映射为键盘操作。

## 4. 系统结构

```text
摄像头
  -> 中央区域裁剪
  -> MobileNetV3-Small 分类
  -> 置信度过滤
  -> 连续帧稳定判断
  -> 冷却时间控制
  -> 键盘动作映射
  -> PPT/视频播放器
```

## 5. 模型选择

项目使用 MobileNetV3-Small：

- 参数量较小；
- CPU 推理速度较快；
- ImageNet 预训练后适合迁移学习；
- 修改最后的分类层即可用于四种手势。

训练时可以选择：

- 冻结主干，只训练分类层；
- 微调全部参数；
- 类别加权损失；
- 数据增强。

## 6. 数据采集

每种手势建议采集 100～300 张，训练集和验证集使用不同 session。

需要覆盖：

- 不同背景；
- 不同光照；
- 左手和右手；
- 手与摄像头的距离变化；
- 手势角度变化；
- 不同人员和摄像头位置。

不允许把同一段连续录像的相邻帧随机分到训练集和验证集，因为这会造成数据泄漏，使验证效果虚高。

## 7. 防误触设计

如果模型每帧都发送按键，会出现大量重复操作。因此需要三个限制：

1. **置信度阈值**：低置信度预测不触发；
2. **连续帧数**：同一手势连续出现若干帧才触发；
3. **冷却时间**：同一动作在短时间内只能执行一次。

这套逻辑放在 `stability.py` 中，可以独立测试，不依赖摄像头。

## 8. 键盘控制设计

动作映射放在 `configs/actions.json`：

```json
{
  "palm": { "action": "play_pause", "key": "space" },
  "peace": { "action": "next", "key": "right" },
  "thumbs_up": { "action": "previous", "key": "left" },
  "fist": { "action": "mute", "key": "m" }
}
```

实际发送按键需要显式添加 `--enable-controls`。默认只预览，避免程序误操作前台窗口。

## 9. 实验设计

### 实验一：基础分类

比较冻结主干和完整微调的准确率、Macro F1、训练时间和模型大小。

### 实验二：数据增强

比较不使用增强、随机裁剪、颜色扰动和翻转的效果。

### 实验三：背景影响

收集不同背景下的数据，测试模型是否依赖固定背景。

### 实验四：光照与距离

测试暗光、逆光、手距离变化和部分遮挡。

### 实验五：防误触发参数

比较不同稳定帧数、置信度阈值和冷却时间：

- 误触发次数；
- 漏触发次数；
- 平均响应时间；
- 连续操作成功率。

### 实验六：实时性能

测量：

- 每帧推理时间；
- FPS；
- CPU 占用；
- GPU 与 CPU 的差异；
- ONNX 导出后的速度。

## 10. 评价指标

分类指标：

- Accuracy；
- Macro F1；
- 每类召回率；
- 混淆矩阵。

交互指标：

- 误触发次数；
- 漏触发次数；
- 从手势出现到动作执行的延迟；
- 连续演示时操作成功率；
- 实时 FPS。

## 11. 预期成果

- 一个可训练的四种手势分类模型；
- 一个摄像头实时识别 Demo；
- 一套手势到 PPT/视频按键的映射；
- 一套稳定帧和冷却时间防误触机制；
- 对背景、光照、距离和实时性能的实验分析；
- 可提交 GitHub 的完整工程。

## 12. 后续扩展

1. 使用手部关键点辅助分类；
2. 使用时序模型识别挥手、画圈等动态手势；
3. 加入手势组合和密码式操作；
4. 增加无接触鼠标；
5. 使用 ONNX Runtime 或 TensorRT 部署；
6. 研究不同用户之间的个性化适配。
